# 🏋️ Telegram-бот для учёта тренировок (Workout Bot)

![Coverage](./coverage.svg)

Персональный бот-дневник тренировок прямо в Telegram: планируешь программы,
записываешь факт, отслеживаешь прогресс, рекорды и получаешь достижения.

## 🚀 Основные возможности (C1)

- **Справочник:** создание тренировок и упражнений (силовые и кардио).
- **Умные подсказки:** бот автоматически подтягивает веса и повторения из прошлой тренировки с указанием даты.
- **Текстовый вес:** можно писать «Своё тело», «Резинка», «10 блоков» вместо чисел.
- **Опциональные упражнения:** разминки/заминки не портят статистику, если их пропустить.
- **Таймеры отдыха:** 60с, 90с, 3 мин, своё время — с фоновыми уведомлениями и автоудалением.
- **Цифровые клавиатуры:** ввод весов и повторений через inline-кнопки.
- **Заметки:** комментарии к упражнению и ко всей тренировке.
- **Умная ротация:** тренировку, которую давно не делал, бот поднимает вверх меню.
- **Архив и безопасное удаление:** нельзя случайно удалить то, что имеет историю.

## 📅 Аналитика (C2.5)

- **Месячный дашборд:** тренировки, подходы, упражнения, общее время, тоннаж.
- **Топ упражнений** месяца по подходам с лучшим результатом.
- **Средний отдых между подходами** (медиана, перерывы > 10 мин не считаются).
- **Средний отдых между упражнениями** (медиана перехода от последнего подхода одного упражнения к первому подходу следующего, перерывы > 20 мин не считаются).
- **График активности** по неделям месяца (тренировки и уникальные упражнения).
- **История и детали:** просмотр любой прошедшей тренировки.

## 🏆 Рекорды и достижения (C2.6)

- **Автодетект рекордов (PR):** бот сравнивает каждый подход со всей предыдущей
  историей упражнения и поздравляет мгновенным уведомлением (автоудаление 15 сек).
  Единые правила сравнения для веса (включая текстовые единицы: кг/блоки/своё тело)
  и для кардио (длительность, когда вес не указан).
- **Строка рекорда на экране подхода:** «🏆 Рекорд: 100 кг от 12.11».
- **14 достижений:** рубежи по числу тренировок (10/50/100/250), месячный ритм
  (12 и 20 тренировок за календарный месяц), разнообразие упражнений (10/25/50),
  рекорды (первый, 10, 50, 3+ за тренировку), рост веса +20% к базе первых 30 дней.
- **Экран «🏆 Ачивки»** в аналитике: с прогрессом по каждому замку, молчаливым
  зачётом прошлых заслуг при первом открытии и кнопкой обновления.

## 🧠 Ключевая логика (под капотом)

### План vs Факт
- **План (шаблон)** — настраивается в меню «Упражнения»: целевые подходы, повторы, вес.
- **Факт (активная тренировка)** — ввод фактических данных не меняет шаблон, а создаёт историю.

### Приоритет истории и плана
- **Вес и повторения** подтягиваются из последнего выполненного подхода («В прошлый раз (дата)» + кнопка автозаполнения).
- **Количество подходов** берётся из шаблона; лишние добавляются кнопкой «Добавить подход».

### Архитектура
```
handlers/   — события Telegram (aiogram 3, Router + FSM)
services/   — чистая бизнес-логика (PR, достижения, аналитика) — без БД и Telegram, легко тестируется
db/         — SQLAlchemy 2.0 async: модели и запросы
```

### Архив
- Архивация прячет упражнение/тренировку из глаз, но сохраняет все подходы и заметки.

## 📦 Технический стек

- **Язык:** Python 3.12
- **Библиотеки:** aiogram 3.x, SQLAlchemy 2.0 (async + asyncpg), Alembic
- **База данных:** PostgreSQL 16 в Docker-контейнере
- **Тесты:** pytest + pytest-asyncio (SQLite+aiosqlite в памяти), CI через GitHub Actions с бейджем покрытия
- **Деплой:** Docker Compose, автоматические дампы БД
