# 🗺️ Roadmap: C2 (История и Прогресс)

## Подшаги
- [x] **C2.1 — Раздел «📊 История» (базовый):** Кнопка в меню, список прошлых тренировок с датой и кратким итогом. Пагинация.
- [x] **C2.2 — Просмотр сессии (детали):** Тап на тренировку открывает полный отчёт (упражнения, подходы, тоннаж, заметки, длительность, интервалы).
- [x] **C2.3 — Прогресс по упражнению (графики):** Кнопка «📈 Прогресс» в карточке. График веса (matplotlib), рекорды, средние.
- [x] **C2.4 — Кнопка «Сделать планом» на экране итогов:** После выполнения упражнения обновить шаблон (вес/повторы) в один клик.
- [x] **C2.5 — Аналитика (дашборд):** За месяц: тоннаж, любимое упражнение, средний отдых. График по неделям.
- [x] **C2.6 — Личные рекорды и достижения (геймификация):**
  - [x] **Блок 1 (PR):** Автоопределение рекордов: мгновенные уведомления (auto-delete 15 сек), итоговый блок «Рекорды за тренировку», сравнение веса по единицам измерения (кг/блоки/резина не смешиваются).
  - [x] **Блок 4 (CSV-экспорт):** Три селективных вида: история упражнения (с экрана прогресса: дата, тренировка, подход, вес, повторы, длительность для кардио, интервал), тренировки за месяц (из аналитики: дата, тип, упражнения, подходы, время ч/мин, строгий тоннаж), детальный экспорт одной тренировки (подходы с отдыхом после каждого; кнопка в деталях и на экране итогов). UTF-8 BOM + «;» — Excel открывает по двойному клику. Фикс навигации: «Назад» из ленты заметок ведёт на экран прогресса. Средний отдых между подходами на экране прогресса и в деталях тренировки, длительность в ч/мин на экранах.
  - [x] **Блок 3 (Ачивки):** Экран «🏆 Ачивки» в аналитике (14 ачивок: тренировки 10/50/100/250, месячный ритм 12/20, PR 1/10/50, 3+ PR за тренировку, Вес +20%, разнообразие 10/25/50). Мгновенное уведомление при завершении тренировки, ретро-выдача за прошлую историю, строка «🏆 Рекорд» на экране подхода.

## C2.7 — Сезоны и ретроспектива (следующий мини-блок, C2.6 закрыт)
- [x] **Сезонные челленджи:** ачивки с кодом периода без миграции БД. Первый — 12 завершённых тренировок за декабрь 2026 (`monthly_12_2026_12`). В секции «Сезонные» видны дата старта или прогресс, с 1 января результат доступен в отдельном архиве. Месяц определяется по началу каждой завершённой тренировки в МСК.
  - Вторая декабрьская цель — личный рекорд в 3 разных упражнениях (`pr_exercises_3_2026_12`). Упражнение определяется по паре «название + тип» и засчитывается один раз. Результат сравнивается со всей предыдущей историей завершённых тренировок по правилам PR.
  - Под прогрессом и в архиве видны первые три зачтённых упражнения и последний PR каждого за период. Новый PR того же упражнения обновляет показанный результат без нового балла. Сверх цели показывается число остальных.
  - Цели одного периода сгруппированы под общим заголовком. Дата старта показывается один раз, отметка о выполнении стоит у своей цели.
  - Постоянные ачивки показывают условие выдачи после получения и до получения, если у ачивки нет числового прогресса.
- [x] **Рекордная доска:** отдельный экран «🏅 Лучшее» за всю историю. Лучший месяц и неделя (пн–вс) по числу завершённых тренировок, рекордный строгий тоннаж одной тренировки. Периоды по началу тренировки в МСК. При равенстве выигрывает более ранний результат. Кнопки в два ряда: график и экспорт, ачивки и лучшее. Возврат к исходному месяцу.
  - На экране «🏅 Лучшее» заголовок и результат каждого рекорда выведены в отдельные строки. Диапазон недели записан словами, общие месяцы и годы не повторяются.
  - Если есть рекорд тоннажа, «Рекордная тренировка» стоит в одном ряду с «Назад к аналитике» и открывает детали этой сессии. Кнопка возврата в деталях ведёт обратно на доску.
  - Под заголовком доски пояснение «Только завершённые тренировки» и разделитель перед результатами.
- [x] **Ретроспектива**
  - [x] **Годовая:** в аналитике «📊 Итоги» с количеством и временем тренировок, самым активным месяцем и числом упражнений с PR. Текущий год доступен с 1 декабря по МСК как предварительный итог. При первом открытии закрытого года с тренировками выдаётся памятная ачивка.
  - [x] **Сезонная:** в итогах можно переключаться между годом и сезонами с завершёнными тренировками. Текущий сезон показывается на сегодня. Зима начинается 1 декабря и заканчивается перед 1 марта по МСК.
  - В годовых итогах в одном ряду «Сезонные итоги» и «Назад к аналитике». Из сезонов «Назад к годовым итогам» возвращает к ранее открытому году. Стрелки между периодами — отдельным рядом выше.
- [x] **Alembic:** начальная ревизия `0001` проверена на пустом PostgreSQL 16 и на временной базе с уже созданной схемой и вымышленной записью.
- [x] **Фиксируемый архив челленджей.** Активные цели пересчитываются по истории, закрытый итог сохраняется один раз.
  - [x] Миграция `0002` добавляет уникальную запись на пользователя, месяц и цель. Запись хранит название цели, единицу измерения, порог, фактический результат, статус, детали и момент фиксации.
  - [x] Подключены сохранение и чтение итогов, автоповтор и настройка целей по месяцам через `MONTHLY_GOAL_OVERRIDES`. Для новых показателей добавляются правила подсчёта.
  - Первый фиксируемый итог — декабрь 2026. С января 2027 по умолчанию повторяются обе цели: 12 завершённых тренировок и личный рекорд в 3 разных упражнениях. Все закрытые периоды доступны в общем архиве со своими условиями и результатами.
  - Зачёт идёт по дате начала тренировки в МСК после её завершения. Новый период открывается в полночь, даже если предыдущий ждёт завершения или отмены начатой в нём тренировки. После простоя бот обработает пропущенные закрытия при запуске.
